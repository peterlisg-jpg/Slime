角色 Spine 骨架方案 v1

这是把「一张平面图」升级成「会呼吸的软体角色」的施工图。原画按第 1 节拆件，Spine 按第 3–4 节绑骨，程序按第 7 节接运行时。三个角色共用一套骨架，只换皮肤。

02为什么要拆成这样

拆件的标准只有一条：凡是需要独立运动的，就必须独立成层。下面是每个动作真正会用到的自由度。

3

身体骨

hip → spine1 → spine2 → head，撑起挤压、拉伸、弯曲。软体就靠这三节。

2

眼睛

眼白与瞳孔分开，才能实现「看钩子」「看队友」「眨眼不带动瞳孔」。

6

口型

六个嘴型覆盖全部情绪，换 attachment 即可，不需要额外动画。

2×4

触手骨

每条四节 + IK，抓钩、拉人、甩出全靠它。这是「没有手」的解法。

1

头顶泥滴

用 transform 约束延迟跟随，产生二次运动，成本极低但一眼就「活」。

1

漂浮泥滴

独立 slot，自己做正弦漂浮，和身体解耦。

03骨骼层级

Y 轴向上（Spine 默认）。hip 是唯一根骨，所有运动都从它派生，程序只需要控制 hip、两条 IK 目标、两个眼骨。

root
└─ hip                        # 轴心在脚底中心 (1032, 1876)
   ├─ spine1                    # 长度 ≈ 276
   │  └─ spine2                 # 长度 ≈ 350
   │     └─ head                # 长度 ≈ 460，末端在头顶
   │        ├─ eye_L  → pupil_L → eye_hi_L
   │        ├─ eye_R  → pupil_R → eye_hi_R
   │        ├─ mouth          # attachment 切换 6 个口型
   │        ├─ blush_L / blush_R
   │        └─ drip_head        # transform 约束：跟随 head 70%，延迟 120ms
   ├─ drip_top                 # 独立 slot，正弦漂浮
   ├─ tent_L1 → L2 → L3 → L4   # IK 约束，目标 ik_L
   └─ tent_R1 → R2 → R3 → R4   # IK 约束，目标 ik_R
程序只需要碰 5 个东西：hip（位置/旋转）、ik_L、ik_R（世界坐标）、eye_L、eye_R（看向目标）。其余全部由动画和约束自己算。

04网格与权重

对象网格权重
body_base8 × 8（81 顶点）按高度平滑混合：底部→hip，中部→spine1，上部→spine2，顶部→head。每顶点最多 2 骨。
tentacle_L/R6 × 2沿长度线性绑到 4 节骨，根端 100% 绑 L1。
body_hi8 × 8，与 base 同拓扑用 Linked Mesh 跟随 base，避免两套权重不同步。
眼 / 嘴 / 泥滴Region（不建网格）刚性跟随父骨即可。

为什么是 8×8

软体需要的是「平滑的曲线」，不是高密度。8×8 在弯腰 35° 时仍然看不见棱角，同时保持权重可手调；12×12 以上只会增加调试成本。

必须做的三件事

  • 腰部（spine1 附近）权重过渡要有 2 行渐变，否则弯腰会「折纸」。
  • 底部两行锁定 hip，保证脚不飘。
  • 所有边缘留 4px 扩边（bleed），否则网格拉伸会露出透明缝。

05约束

类型对象参数用途
IKtent_L1…L4 → ik_L链长 4，允许拉伸，softness 0抓钩时把末端钉在钩子上，身体被拉长
IKtent_R1…R4 → ik_R同上拉队友、甩出
Transformdrip_head ← head旋转 70%，位移 60%，延迟 0.12s头部泥滴的跟随惯性
Transformeye_hi_L/R ← pupil100% 跟随高光永远在瞳孔上

顺序很重要：先 IK，再 Transform。Spine 的约束按列表顺序求解，顺序错了会出现「泥滴追不上头」的抖动。

06动画清单

Clip帧数 @30循环关键点事件
idle60是呼吸挤压 ±3%，每 90±30 帧眨眼，泥滴摆动—
grab18否触手甩出 → 钉住 → 身体被拉长，头滞后grab_on
pull30是身体后仰、发力，另一条触手朝队友伸strain
fling15否松手瞬间的拉伸 + 回弹，身体拉成水滴形fling
land20否落地压扁 25% → 回弹过冲 → 稳定land
dizzy45是左右摇晃，口型切到晕眩，眼睛转圈—

口型不单独做动画：在 clip 里打 attachment 关键帧切换 mouth_01…06，一个 clip 内可多次切换。

07运行时接口

现在的 stage.js 负责场景、镜头、光。角色层换成 Spine 之后，只需要保留下面这几个调用。

// 加载
const atlas = new spine.TextureAtlas("limeland_char.atlas", loader);
const skel  = new spine.SkeletonJson(new spine.AtlasAttachmentLoader(atlas))
                 .readSkeletonData(rawData);

// 皮肤与初始动作
skeleton.setSkinByName("green");          // 或 "pink"
skeleton.setSlotsToSetupPose();
state.setAnimation(0, "idle", true);

// 动作切换（不打断循环）
state.setAnimation(1, "grab", false);
state.addAnimation(1, "pull", true, 0);

// 事件驱动特效 / 音效
state.addListener({
  event: (entry, e) => {
    if (e.data.name === "fling") fx.burst(...);
    if (e.data.name === "grab_on") sfx.grab();
  }
});

// 每帧：把钩子世界坐标喂给 IK 目标
ikL.setPosition(hook.x, hook.y);          // 骨骼世界坐标，Y 向上
ikR.setPosition(partner.x, partner.y);

// 眼睛看向
eyeL.setRotation(clamp(angleTo(target) - baseAngle, -12, 12));

09验收标准

这五条过了，才算这一版落地；任何一条不过，都说明拆件或权重需要返工。

  • 把 spine2 旋转 ±35°，身体轮廓连续，没有接缝、没有折角、没有穿刺。
  • IK 触手能伸到 700px 外的钩子，末端不脱离目标，身体被自然拉长。
  • 眨眼时瞳孔和高光不跟着消失，只在眼白内闭合。
  • 切换 green / pink 皮肤后，网格和动画完全一致，不出现错位。
  • 1080p 下角色高 260px，边缘干净，没有 1px 亮边或暗边（PMA 正确）。
