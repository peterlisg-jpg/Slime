# 《拉丝 LIMELAND》产品策划案

**版本**：v0.3（单屏清场垂直切片）
**日期**：2026-11-20
**状态**：可玩切片已实现；美术为占位资产；玩法方向已定
**一句话**：两个史莱姆，一根绳，在霓虹便利店里把货架清干净。

---

## 0. 摘要

- **类型**：2 人本地合作 · 单屏街机动作 · 物理平台
- **核心动词**：扔泥球 → 裹住敌人 → 滚出去撞人；绳子负责甩、荡、拽、踩头
- **结构**：一块屏一波敌人，清完进下一波；3 波一局，60 秒，共享 3 颗心
- **方向**：Snow Bros. 的清场循环 + Pac-Man 的货架迷宫关卡 + 莱姆尼社的霓虹店世界观
- **平台**：PC（Steam / 单文件 Demo）、街机机台、展会试玩
- **明确不做**：全 3D 重制（已试过，方向不对，回退到 2.5D）

---

## 1. 产品定位

| 项目 | 内容 |
|---|---|
| 名称 | 《拉丝》/ LIMELAND |
| 类型 | 2P 本地合作 · 单屏街机动作 · 轻物理 |
| 视角 | 2.5D 侧视，固定单屏，不卷轴 |
| 人数 | 1–2 人（2 人为设计基准） |
| 单局 | 60 秒 / 3 波 |
| 单次会话 | 5–15 分钟（连续刷关） |
| 目标用户 | 14–35 岁，喜欢胡闹合作、派对游戏、街机复古的玩家；展会/机台人群 |
| 核心体验 | “两个人一根绳，手忙脚乱又忍不住笑” |
| 差异点 | 绳子既是移动工具也是攻击工具；清场靠“裹+滚”而不是射击 |
| 参考 | Snow Bros.、Bubble Bobble、Pac-Man、Fling to the Finish、Chained Together、Pico Park |

**设计支柱**

1. **一根绳，两个人**：所有动作都要经过对方。拉、甩、踩头、被拖走，都是合作。
2. **一屏一清场**：没有跑图，进屏就打，30 秒内看懂，60 秒内打完。
3. **可爱但紧张**：史莱姆很软，时间很短，连击很爽。

## 2. 世界观与品牌

### 2.1 世界观

**莱姆尼社**是一家开在史莱姆世界的 24 小时霓虹便利店。货架上卖披萨、汽水、荧光涂料和来路不明的果冻。店里的两个店员——绿泥和粉泥——被一根“芝士拉丝”连在一起，负责在关门前把闹事的商品清出去。

- 第 1 关 **夜光画室**：店后面的画室，霓虹灯、颜料罐、展台、卷帘门。
- 后续区域：**冷柜区**、**收银台**、**仓库**、**店长办公室**。

### 2.2 角色

| 角色 | 形象 | 性格 | 玩法差异（计划） |
|---|---|---|---|
| 绿泥 | 绿色滴落泥团，大眼，笑嘴 | 莽、先冲再说 | 略重，拉人更稳 |
| 粉泥 | 粉色滴落泥团，大眼，笑嘴 | 精、爱指挥 | 略轻，被甩更远 |

当前版本两人数值相同，差异只做视觉。

### 2.3 品牌符号

- **绳子 = 芝士拉丝**：两人之间的绳不是普通绳，是“拉丝的芝士”。这是品牌图形，也是标题的由来。
- **标题字**：ZCOOL 庆科黄油体（已裁子集，111KB，可离线）。
- **语气**：不卖萌，不装酷；像两个店员在店里互相坑。

## 3. 核心玩法

### 3.1 核心循环

```
进入一屏 → 观察敌人分布 → 扔泥球裹住一个 → 滚出去撞一串
   ↑                                        ↓
   └──────── 清场 / 连击 / 分数 ←──────────┘
```

局内循环：**扔 → 裹 → 滚 → 连击 → 清场 → 下一波**。
局外循环：**清 3 波 → 结算（用时/击破/连击/评级）→ 再来一局**。

### 3.2 动词表

| 动词 | 输入 | 作用 | 合作点 |
|---|---|---|---|
| 移动 | A/D（P1）、←/→（P2） | 左右跑 | 绳子会互相拖拽 |
| 跳 | W / ↑ | 跳跃，可踩头 | 踩队友头够高处 |
| 扔泥球 | S / ↓ | 发射泥球 | 把敌人裹成球 |
| 滚球 | 自动 | 裹住的球继续滚，撞人 | 球路可被队友改变 |
| 拉绳 | F / J | 把队友拽过来 | 救人或拉开距离 |
| 甩 | 绷紧时起跳 | 弹射 | 两人配合过缺口 |
| 推挤 | 身体接触 | 互相推开 + 挤压变形 | 抢位置、卡位 |

### 3.3 绳子系统

| 参数 | 当前值 | 说明 |
|---|---|---|
| 自然长度 | 330 | 超过开始拉紧 |
| 最大长度 | 640 | 物理约束上限 |
| 拉绳速度 | 680 | 按 F/J 收绳 |
| 甩出阈值 | 350 | 超过即可触发甩 |
| 甩出推力 | 320 | 水平 |
| 甩出升力 | 1.14× | 跳跃倍率 |
| 视觉 | 3 层（柔光/绳体/高光芯）+ 5 颗水滴 | 已实现 |

- 张力条 10 段，满格变琥珀，提示“满格可甩出”。
- 绳子是**双刃剑**：拉得太紧会互相拖累，松了才能各自走位。

### 3.4 扔 / 裹 / 滚（核心）

| 参数 | 当前值 |
|---|---|
| 泥球速度 | 640 |
| 投掷冷却 | 0.34 秒 |
| 泥球寿命 | 2.0 秒（未命中）/ 2.4 秒（裹住后） |
| 命中半径 | 42 |
| 投掷起点 | 角色脚上 70 |
| 裹住后速度 | 原速度 ×0.6 |
| 连击窗口 | 2.6 秒 |
| 单次得分 | 100 × 当前连击 |

规则：

1. 泥球命中第一个敌人 → 敌人被“裹住”，从敌人列表移除，泥球变成**滚动球**。
2. 滚动球继续移动，撞到下一个敌人 → 连击 +1，得分 ×2，继续滚。
3. 连击窗口 2.6 秒，超时归零。
4. 球碰墙反弹，落地弹跳；时间到或滚出边界后消失。
5. 被裹住的敌人算“已击破”，但球还在场上，不阻塞清场判定。

### 3.5 角色碰撞

- 两人靠近会互相推开，带挤压变形、白色粒子、屏震和“啵”的音效。
- 从上方落到队友头上会自动站住，底下的人被压扁。
- 站在头上会被带着走，也能从头上起跳。
- 深度排序按高度动态决定，高的画在上面。

### 3.6 生命、时间、失败

| 项目 | 规则 |
|---|---|
| 生命 | 共享 3 颗心 |
| 受伤 | 碰到敌人扣 1 颗，击退 + 1.1 秒无敌 + 闪烁 |
| 回血 | 吃披萨 +1（上限 3） |
| 时间 | 60 秒 |
| 失败 | 心扣完 / 时间到 |
| 胜利 | 清完 3 波 |

### 3.7 计分与评级

- 击破：100 × 连击。
- 结算：用时、击破数、最高连击。
- 评级：S / A / B / C。
  - 通关 + 3 心 + 时间 > 15 秒 + 分数 ≥ 3000 → S
  - 通关 + 2 心 → A
  - 通关 + 1 心 → B
  - 失败 → C
- 本地最高分：`limeland.arena.best`。

## 4. 关卡与内容

### 4.1 单屏结构（当前切片）

画布 1280×720，固定镜头，不卷轴。

| 平台 | X 范围 | 高度 Y |
|---|---|---|
| 地面 | 0–1280 | 0 |
| 左货架 | 120–520 | 180 |
| 右货架 | 760–1160 | 180 |
| 中层展台 | 430–850 | 350 |

- 出生点：P1 x=300，P2 x=620。
- 披萨： (300,300)、(980,300)、(640,470)。
- 跳跃高度约 198，可从地面跳上 180 货架，再从货架跳上 350 展台。

### 4.2 波次表（当前切片）

| 波次 | 敌人 | 说明 |
|---|---|---|
| 1 | 果冻 ×2（左右货架）+ 扫地机器人 ×1（地面） | 教学波，地面/货架各一个 |
| 2 | 扫地机器人 ×2（地面）+ 披萨盒 ×1（空中） | 逼玩家上展台 |
| 3 | 果冻（展台）+ 披萨盒（空中）+ 扫地机器人 + 果冻（右货架） | 综合波 |

### 4.3 难度曲线

- 第 1 波：单一高度，教会“扔—裹—滚”。
- 第 2 波：地面 + 空中，要求换位和跳跃投掷。
- 第 3 波：多高度混合，要求连击和清场顺序。

### 4.4 后续关卡类型

| 类型 | 参考 | 玩法 |
|---|---|---|
| 标准清场 | Snow Bros. | 一块屏，3 波，清完过关 |
| 货架迷宫 | Pac-Man | 货架构成迷宫，店长拿手电筒追，青柠汽水当能量豆 |
| 传送带 | 街机机关 | 地面单向移动，投掷要预判 |
| 冷库 | 冰面 | 摩擦力降低，绳子更容易拉过头 |
| 收银台 Boss | 街机 Boss | 店长三阶段 |

### 4.5 Boss：店长

- **阶段 1**：推购物车冲撞，撞墙后短暂眩晕，可被裹住。
- **阶段 2**：扔罐头（抛物线），地面出现落点提示。
- **阶段 3**：叫扫地机器人增援，玩家需要先清小怪再打本体。
- 弱点：背后；被裹住后需要队友滚球撞。
- 目标时长：60–90 秒。

### 4.6 内容量规划

| 阶段 | 内容 |
|---|---|
| 垂直切片（当前） | 1 屏、3 波、3 种敌人、计分、评级 |
| 试玩版 | 6 屏、1 个 Boss、2 种关卡类型、排行榜 |
| 正式版 | 20 屏、4 个区域、4 个 Boss、2 种模式（主线 + 街机） |

## 7. UI / UX

### 7.1 HUD

- 左上：关卡编号、关卡名、3 颗心、分数。
- 中上：本波清场进度条、第 N 波 / 3、剩余敌人数。
- 右上：环形倒计时、披萨收集图标。
- 左下：绳子张力 10 段条、状态提示。
- 右下：A/D/W/F/S 键帽提示。
- 提示条：屏幕上方居中，带莱姆绿左边框。

### 7.2 界面流程

```
标题 → 关卡卡 → 3-2-1-GO → 游戏 → 暂停 / 结算 → 再来一局 / 回标题
```

- 标题：游戏字标、关卡标签、开始按钮、键位说明。
- 关卡卡：LEVEL 01 / 夜光画室 / 目标。
- 倒计时：3、2、1、GO，带音效。
- 暂停：面板 + 选中条，继续 / 重开 / 音量 / 回标题。
- 结算：评级、星级、用时 / 击破 / 最高连击、最高分、再来一局。

### 7.3 反馈

- 命中：粒子、圆环、音效、连击文字。
- 受伤：红闪、屏震、击退、无敌闪烁。
- 清场：进度条填满、波次提示。
- 甩出：屏震、残影、提示“甩出去了！”。

### 7.4 可访问性（计划）

- 屏幕震动开关。
- 色盲模式（敌人加形状差异，不只靠颜色）。
- 键位重映射。
- 单手模式（P2 可托管）。

## 8. 美术方向

- **风格**：2.5D 霓虹便利店，深靛紫底，莱姆绿/粉/青/琥珀，软胶质感。
- **角色**：滴落泥团、大眼、小嘴；当前为 2D 裁切 + 2.5D 厚度。
- **场景**：货架、展台、霓虹灯、卷帘门、披萨盒。
- **已知问题**：平铺背景 + 平面角色容易“像贴图”；解决方案是分层背景 + 角色 Spine / 手绘道具，而不是继续加光。
- **已否决**：全 3D 重制（样张两次未通过，回到 2.5D）。
- **美术资产清单（待补）**：
  1. 4 层背景（远景墙 / 中景货架 / 玩法层 / 前景遮挡）。
  2. 绿/粉角色分层（身体、眼睛、嘴、滴落）。
  3. 3 种敌人各 4–6 帧动画。
  4. 3 种披萨/道具。
  5. 店长 Boss 三阶段。
  6. UI 图标一套。

## 9. 音频

- **音乐**：118 BPM，四四拍；底鼓 + 军鼓 + 踩镲；低音 riff；反拍和弦 stab；方波主旋律；最后 10 秒加密踩镲。
- **动态**：探索层 / 紧张层（时间 < 10 秒）。
- **音效**：

| 事件 | 声音 |
|---|---|
| 跳 | 440Hz 正弦，0.1 秒 |
| 甩出 | 760Hz 三角，0.16 秒 |
| 扔球 | 520Hz 方波，0.07 秒 |
| 裹住/连击 | 700Hz + 60×连击，三角 |
| 受伤 | 120Hz 锯齿，0.2 秒 |
| 吃披萨 | 900Hz 三角 |
| 清场 | 上行三音 |
| 倒计时 | 440/880Hz |

- 混音：音乐总线 0.26，主音量 0.9，音效独立总线。

## 10. 技术方案

| 项目 | 方案 |
|---|---|
| 引擎 | Three.js（本地 `lib/`，无 CDN） |
| 渲染 | 透视相机（fov 30）、固定 1280×720、Bloom + OutputPass、ACES |
| 物理 | 自写 2D 物理，固定步长 1/120 秒；绳子 Verlet 链 22 节 |
| 角色 | 2D 裁切 + 自定义 Shader（漫反射/高光/边缘光） |
| 敌人 | Sprite + Canvas 贴图，程序化 |
| UI | DOM + CSS，独立于 3D |
| 打包 | esbuild 打成 IIFE，资源 Base64 内联，单文件 1.7MB |
| 离线 | 字体子集 111KB，图片压缩，单文件双击可玩 |
| 遥测 | 本地日志 + 结算摘要；预留上报接口 |
| 性能目标 | 1080p / 60fps / 集显 |

**已知技术问题**

- 两个角色重叠时的边缘闪烁：已改为透明混合 + 固定渲染顺序，待真机确认。
- 绳子与前景的排序：已用 renderOrder 分层（角色 10/11、绳子 20、敌人 30）。
- WebGL 依赖：无 WebGL2 的机器直接提示，不做降级。

## 14. 风险与未决

| 风险 | 影响 | 对策 |
|---|---|---|
| 美术资产不足 | “像贴图”、卖相差 | 先定 4 层背景 + 角色分层；不再用代码硬补 |
| 绳子在迷宫里打架 | Pac-Man 关卡体验差 | 迷宫关限定短局、加宽走道、允许松绳 |
| 2 人门槛 | 单人玩家流失 | 单人模式（AI 队友/双角色切换） |
| 内容量 | 独立游戏需要 2–4 小时内容 | 20 屏 + 4 Boss + 街机模式 |
| 难度曲线 | 新手 60 秒内死光 | 前 3 屏教学、动态波次、披萨回血 |
| 连击不可读 | 玩家不知道发生了什么 | 连击文字、球路高亮、音效递增 |
| 在线联机 | 成本高 | 先做本地 + Remote Play Together |
| 3D 重制诱惑 | 重复踩坑 | 已明确否决，2.5D 为唯一方向 |

**待决策**

1. 美术管线：手绘分层 + Spine，还是低模 3D 渲染成 2D？
2. 是否做单人模式？
3. 在线联机是否进正式版？
4. 定价与发行方式（EA / 正式 / 机台先行）？
5. 正式版关卡数量与 Boss 数量。
